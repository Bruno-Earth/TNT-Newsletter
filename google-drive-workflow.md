# Google Drive Review Workflow

## Recommended Approach

Use Google Drive as the review and archive location, but keep the first generator local and manual.

This is the most cost-efficient and workflow-efficient path because it avoids paid publishing tools, avoids fragile API setup too early, and keeps every draft under your work account ownership.

## Phase 1: Manual Upload

1. Generate the daily package locally.
2. Review the package folder.
3. Upload the full folder to:

```text
Google Drive / TNT Capital / Newsletter Drafts
```

4. Review HTML drafts, PDFs, sources, and compliance checklist.
5. Approve, request edits, or archive.

## Phase 2: Google Drive for Desktop

Install Google Drive for Desktop and set the generator output folder to a synced Google Drive folder.

Recommended local synced path:

```text
Google Drive / TNT Capital / Newsletter Drafts
```

This gives automatic folder sync without needing API credentials.

## Phase 3: Google Drive API

Use this only after the newsletter format is stable.

Best use cases:

- Automatic folder creation
- Automatic upload
- Versioned archive
- Sharing links
- Team notification after draft creation

## Why Not Email Platform First

Email platforms are useful later, but they add approval and formatting complexity early. HTML email plus PDF drafts are easier to control while the editorial system is still being trained.
