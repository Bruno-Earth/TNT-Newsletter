# First Run Checklist

## Before First Draft

- Approve or reject the proposed source list.
- Add any private or preferred sources.
- Confirm whether paid data sources are allowed later.
- Confirm Google Drive folder name and sharing access.
- Confirm whether the English Boston-time version should be a morning brief or an after-Vietnam-close brief.

## First Manual Draft Run

- Create the daily review package.
- Check that both HTML files open correctly.
- Export both PDFs.
- Confirm disclaimer appears in both PDFs.
- Check that source links are included.
- Check that no buy/sell/hold wording appears.
- Upload the folder to Google Drive for review.

## After First Draft

- Mark sources as approved, rejected, or watchlist.
- Adjust TNT Capital tone and visual density.
- Decide whether charts should be daily or only when useful.
- Decide when to move from manual generation to scheduled generation.
